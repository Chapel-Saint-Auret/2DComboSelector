## Orthogonality Rank

Consensus orthogonality rank obtained from the Borda-based aggregation of the different metric groups defined in “Metric Correlation Analysis”.
 
It is obtained as follows: first, the metrics are grouped based on cross-correlation analysis, then individual metrics are converted into ranks, aggregated within each group using the median to obtain one consensus rank per group. 

Finally, each group ranks are combined using a Borda-type strategy to obtain a final consensus orthogonality rank.
